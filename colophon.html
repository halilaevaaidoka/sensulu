How We Built the Website

This website was created as part of the Introduction to Web Technologies course. We used HTML to organize the content and create the structure of each page. The project contains six HTML pages connected through the navigation menu. Visual Studio Code was used to create and edit the project files.

HTML Examples

We used the <section> element to organize related content on our pages. 


            <section>
            <h2>Products</h2>
            <p>Product information</p>
            </section>

In Visual Studio Code, we press Ctrl + S to save our files.

An example of program output can be shown with the File saved successfully element.

Tools Used

We used Visual Studio Code to write and edit the HTML files. The project files are stored together in the SENSULU project folder. We also used a web browser to open the pages and check the navigation, forms, tables, and page structure.
