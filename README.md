# Sen Sulu — Assignment 1

## Project Description

This project is a website about Sen Sulu, created for the Introduction to Web Technologies course. Assignment 1 focuses on HTML structure and semantic markup.

## Pages

* index.html — Home page.
* about.html — Information about Sen Sulu.
* products.html — Information about products.
* colophon.html — Information about the website and its creation.

## Technologies

* HTML5
* Visual Studio Code

The website runs locally. No CSS, JavaScript, or frameworks are used for Assignment 1.

## How to Open

1. Download the repository files.
2. Open index.html in a web browser.
3. Use the navigation links to visit the other pages.

## Forms

The forms are part of the HTML assignment. No server is connected, so submitted information is not processed or stored by the website.
